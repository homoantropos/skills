# 🔵 SCOLDED — worth noticing

- Same error handled at several levels.
- Dead code (try-catch around handled errors).
- Breaks the undocumented style around it.
- Agreed out-of-task changes missing from commit messages.
- Typos in commit messages.
- App-wide UI rules ignored (dark mode…).
- Stored data without schema version; stale keys.
- Verbose code duplicating existing code.
